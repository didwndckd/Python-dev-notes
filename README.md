# Python-dev-note

점프 투 파이썬([wikidocs.net/book/1](https://wikidocs.net/book/1))을 따라가며 정리한 파이썬 학습 노트.
각 문서는 설명과 예제로 이루어져 있으며, 직접 실행해 본 코드는 [Source](Source)에 있다.

## 자료형

- [숫자형(Number)](Numbers.md) — int, float, 진수 표현, 연산자
- [문자열(String)](String.md) — 문자열 생성, 인덱싱/슬라이싱, 포매팅, 관련 함수
- [리스트(List)](List.md) — 리스트 생성, 인덱싱/슬라이싱, 연산, 관련 함수
- [튜플(Tuple)](Tuple.md) — 튜플 생성, 불변성, 인덱싱/슬라이싱, 연산
- [딕셔너리(Dictionary)](Dictionary.md) — Key:Value 쌍, 추가/삭제, 관련 함수
- [집합(Set)](Set.md) — 집합 생성, 중복 제거, 교집합/합집합/차집합, 관련 함수
- [불(Bool)](Bool.md) — True/False, 자료형의 참과 거짓, 논리 연산자
- [변수(Variable)](Variable.md) — 변수 선언, 명명 규칙, 객체 복사와 참조

## 제어문

- [조건문(if)](If.md) — if/elif/else, 들여쓰기, 조건부 표현식, match-case
- [반복문(while)](While.md) — 기본 구조, break/continue, 무한 루프, while-else, 중첩
- [반복문(for)](For.md) — 기본 구조, range, 리스트 컴프리헨션, enumerate, zip

- [함수(function)](Function.md) — def 구조, 매개변수/인수, \*args/\*\*kwargs, 반환값, scope, lambda
- [사용자 입출력(input/print)](UserIO.md) — input, 형변환, print, sep/end 매개변수
- [파일 읽고 쓰기(file I/O)](FileIO.md) — open, 파일 열기 모드, read/readline/readlines, with문, 인코딩
